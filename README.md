# Zenith Capital Group

Official organization website and business-planning repository for **ZENITH CAPITAL GROUP LLC**, a Tennessee software company developing practical applications and accessibility-focused technology.

Website: <https://zachpoli.github.io/zenith-capital-group/>

## Current project

[FamiliarVoice Notifications](https://github.com/ZachPoli/familiar-voice-notifications) is an Android accessibility prototype that reads messages aloud using sender-specific familiar voices.

## Business roadmap

Zenith's long-term objective is to build cash-flowing software and technology operations, systematize them so they do not depend entirely on the founder, and eventually develop the capability to acquire and operate additional businesses.

## Operating principle

**Worker -> Builder -> Manager -> Owner -> Capital Allocator**

The company should progressively separate income from the founder's physical presence and hours worked through software, systems, people, recurring revenue, and ownership.
