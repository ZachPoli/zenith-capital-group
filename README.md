# Zenith Capital Group

Official website and business-planning repository for **ZENITH CAPITAL GROUP LLC**, a Tennessee software company focused on practical applications, accessibility technology, automation, and data-driven products.

Website: <https://zachpoli.github.io/zenith-capital-group/>

## Current Product Work

### [FamiliarVoice — Public Case Study](https://github.com/ZachPoli/ZachPoli/blob/main/projects/familiarvoice.md)

FamiliarVoice is an Android accessibility prototype that turns supported incoming messages into sender-specific familiar-voice audio. The working MVP has been physically tested with Android devices and Ray-Ban Meta glasses.

The full FamiliarVoice source repository is intentionally private while development continues; the public case study documents the product, technology, testing, and Zachary's work without publishing the complete implementation.

### Career Command Center

Career Command Center is a local-first workflow application for job discovery, opportunity verification, ATS analysis, evidence-based resume tailoring, application tracking, and iterative match-quality improvement.

A sanitized public portfolio release is planned after the private candidate data, credentials, and local production state are fully separated from demonstration data.

## Business Roadmap

Zenith's long-term objective is to build useful software and technology operations, systematize them so they do not depend entirely on the founder's physical presence, and eventually develop the capability to acquire and operate additional businesses.

## Operating Principle

**Worker → Builder → Manager → Owner → Capital Allocator**

The company should progressively separate income from the founder's physical presence and hours worked through software, systems, recurring revenue, people, and ownership.
