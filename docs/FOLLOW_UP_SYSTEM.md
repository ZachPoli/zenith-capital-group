## Core rule

Follow up enough to create a real opportunity, but do not become noise.

- Email/contact-form prospects: one first follow-up, then one final follow-up.
- LinkedIn prospects: do not send repeated connection requests. If the connection is accepted, move into one focused discovery question.
- Any substantive reply immediately overrides the schedule below and moves the prospect into the appropriate pipeline status.

## Response Handling

### Positive response / problem described

1. Move status to **Discovery**.
2. Do not immediately pitch software.
3. Use `docs/DISCOVERY_CALL_PLAYBOOK.md`.
4. Capture the current process, frequency, people involved, time/cost, errors/friction, current tools, desired outcome, and who can approve a change.
5. Only after understanding the problem, propose the smallest useful paid project.

### "Not interested" / "we're good"

Mark **Closed / Not Now**. Thank them and do not argue.

### Referral to another person

Treat the referral as progress. Record the new contact and continue the conversation with context from the referral.

### No response after final follow-up

Mark **Closed / Not Now — No Response**. Do not keep chasing the same person. Replace the prospect with a new qualified company in the pipeline.

## Weekly Operating Rhythm

After this first batch, Zenith should avoid one-day outreach bursts followed by silence.

A sustainable weekly cadence is:

- Add a small number of qualified prospects.
- Send personalized first touches.
- Review replies and connection acceptances.
- Follow up only when due.
- Move real pain into Discovery.
- Keep pipeline notes current.

The goal is not message volume. The goal is a steady flow from **Contacted → Connected → Discovery → Proposal → Won**.
